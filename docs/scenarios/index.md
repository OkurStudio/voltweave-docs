# Example scenarios

Step-by-step builds for typical gameplay situations. The first four use only Blueprints and the ready-made Actors from `Voltweave Content/Blueprints`; the last two describe bays of the [demo hall](../demo.md) so that you can rebuild them.

| Scenario | What you learn |
|---|---|
| [A door that needs power](door.md) | React to a consumer's state in a Blueprint. |
| [An emergency light](emergency-light.md) | Keep a lamp on during a blackout with a battery. |
| [A solar panel with day and night](solar-panel.md) | Drive a source from your own logic. |
| [A fuse box](fuse-box.md) | Protect a line and recover from an overload. |
| [Priorities and brownouts](priorities-and-brownouts.md) | Decide who gets power when there is not enough. |
| [Redundancy](redundancy.md) | Two generators, two paths, and what survives when one fails. |

Every scenario assumes the plugin is [installed](../getting-started/installation.md) and *Show Plugin Content* is on.
