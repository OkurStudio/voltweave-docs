# Support

## Product support

The support contact for the Voltweave plugin will be published with the product listing on Fab. This documentation site does not replace it.

## Documentation feedback

If a page is unclear, wrong or out of date, please open an issue on the documentation repository: [github.com/OkurStudio/voltweave-docs/issues](https://github.com/OkurStudio/voltweave-docs/issues). That tracker is for this documentation only.

## What to include in a bug report

A good report lets us reproduce the problem quickly:

1. Unreal Engine version and the Voltweave version (see the plugin's description in **Edit > Plugins**).
2. Whether it happens in the editor, in Play In Editor, in a packaged game, on a server or on a client.
3. What you expected and what happened.
4. The output of **Build > Check Map** for your level.
5. The output of the console command `Voltweave.Dump` (see [Console commands](api/console.md)) and the relevant lines of the log (category `LogVoltweave`).
6. The smallest setup that shows the problem: the nodes involved, their key properties and how they are wired.

Please do not post the plugin's source code in public places.

See [Troubleshooting](troubleshooting.md) for the most common problems.
